# skein-docs

A mirror of the documentation site of [skein](https://github.com/chasingdaylight/skein), published with GitHub Pages under this repository's custom domain.

There is no content here. The workflow `.github/workflows/pages.yml` checks out skein, builds the site with skein's own script, and publishes it: every day, on a push here, and by hand. To change the documentation, change it in skein.
